너는 전문 웹 퍼블리셔이자 풀스택 프론트엔드 개발자야. 새로운 기업소개용 원페이지 홈페이지를 제작하려고 해. 아래의 요구사항을 완벽하게 숙지하고 코드 작성을 준비해줘.

[프로젝트 핵심 요구사항]
1. 형태: 원페이지(One-Page) 형식의 모던하고 트렌디한 기업소개용 웹사이트 (HTML, CSS, JavaScript 사용)
2. 디자인/이미지 규칙: 
   - 첨부된 디자인 시안(사진)을 참고하되, 시안에 없는 이미지를 대체하기 위해서 쓰이는 도형이나 박스는 그라데이션 효과가 모두 제외된 깔끔한 '단색(Solid Color)'으로 임시 구현할 것.
   - 레이아웃 내 이미지 영역은 배경 이미지(background-image) 가 들어갈 예정이라 이 또한 어두운 무채색 계열로 임시 구현해줘.
3. 내비게이션(Nav) 및 서브페이지 구조:
   - 상단 Nav 카테고리 개수에 맞춰, 클릭 시 이동하거나 뼈대만 확인할 수 있는 '서브페이지 5개'의 틀(HTML 파일 또는 섹션 구조)을 함께 구성할 것.
4. 푸터(Footer):
   - '광고 마케팅 회사'에 어울리는 트렌디하고 전문적인 임시 정보(회사 주소, 사업자등록번호, 대표번호, 이메일, 저작권 표시, SNS 링크 등)를 채워 넣을 것.
5. 참조 파일: 상위 폴더에 포함된 클로드용 마크다운(.md) 가이드 파일을 참고하여 전체 톤앤매너를 맞출 것.
6. 안의 폰트는 대부분 웹폰트 Noto Sans KR 을 연결해서 써줘.
=========================

작성된 웹사이트 코드를 깃허브(GitHub)에 업로드하고, 'GitHub Pages' 기능을 이용해 링크 클릭 시 바로 웹사이트를 확인할 수 있도록 배포하는 방법을 차근차근 단계별로 알려줘.

[포함해야 할 내용]
1. 로컬 환경에서 깃(Git) 초기화 및 커밋하는 명령어
2. 깃허브에 새 리포지토리(Repository)를 만들고 연동하는 방법
3. main 또는 gh-branch를 통해 GitHub Pages 배포를 활성화하는 방법
4. 배포 완료 후 생성되는 라이브 링크(URL) 확인법
